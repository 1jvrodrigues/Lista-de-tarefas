✅ Minhas Tarefas

Uma lista de tarefas simples, bonita e funcional, feita com HTML, CSS e JavaScript puro 

— sem frameworks, sem dependências, só o essencial.

Este foi meu primeiro projeto no GitHub, criado para praticar lógica de programação

🔗 Demo

https://1jvrodrigues.github.io/Lista-de-tarefas/

✨ Funcionalidades
- ➕ Adicionar novas tarefas
- ✔️ Marcar tarefas como concluídas
- 🗑️ Remover tarefas da lista
- 🔢 Contador automático de tarefas pendentes
- 💨 Interface leve, responsiva e com pequenas animações

🛠️ Tecnologias utilizadas
- HTML5 — estrutura da página
- CSS3 — estilização, cores e responsividade
- JavaScript — lógica de adicionar, concluir e remover tarefas

🧠 O que aprendi com este projeto
- Manipulação do DOM com JavaScript
- Como capturar eventos de formulário e clique
- Como organizar dados em um array de objetos
- Boas práticas de organização de arquivos (HTML, CSS e JS separados)
